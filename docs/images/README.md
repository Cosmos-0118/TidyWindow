# README artwork

- `hero.svg` is a compact identity banner with the TidyWindow mark, name and a short description on a plain background.
- `install-hub-light.png`, `cleanup-light.png` and `tune-dark.png` are real TidyWindow 5 app captures on Windows. Package versions, cleanup sizes and setting states are examples from that machine.

To refresh a screenshot, use the same window size, let loading finish and close the hover sidebar. Move the pointer entirely outside the app bounds, then activate the app without moving the pointer before capturing. Check that both the pointer and its highlight are absent. Capture only the app window and keep local paths and personal filenames out of the image. Capturing a scan or settings page does not require running a clean, installing a package or applying a setting.
